## 금일 진행할 사항

### 1. Supabase와 pgvector 기본 구조 학습

* Supabase가 PostgreSQL 기반 서비스라는 점을 확인
* pgvector가 임베딩을 저장하고 유사한 벡터를 검색하는 PostgreSQL 확장 기능임을 학습
* 기존 Qdrant 구조와 Supabase pgvector 구조의 차이를 정리
* SQLAlchemy와 psycopg의 역할을 구분

```text
SQLAlchemy: Python 코드에서 테이블과 쿼리 관리
psycopg: Python과 PostgreSQL 연결
pgvector: 임베딩 저장 및 벡터 거리 검색
Supabase: PostgreSQL DB 호스팅 및 관리
```

* 현재 프로젝트에서는 다음 구현 방식을 우선 적용

```text
Python 연결: SQLAlchemy + psycopg
벡터 타입: pgvector VECTOR
거리 방식: 코사인 거리
벡터 인덱스: 우선 적용하지 않음
```

* 기존 검색 결과 객체와 Supabase 검색 결과 객체의 필드를 일치시키는 방법 정리

### 3. Supabase 테이블 구조 확정

* 임베딩 모델의 실제 출력 차원을 확인한 뒤 벡터 컬럼 차원 확정
