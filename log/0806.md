* 관리자 로그인·로그아웃 API 구현
* 로그인 성공 시 `httpOnly` 세션 쿠키 발급

* 비밀번호 재확인 API 구현
* 관리자 역할과 권한 정보 반환
* 로그인 실패 횟수 및 계정 잠금 처리

대상 API:

```text
POST /api/admin/login
POST /api/admin/logout
GET  /api/admin/session
POST /api/admin/session/extend
POST /api/admin/reauth
GET  /api/admin/roles
GET  /api/admin/me/permissions
```

### 4. 공통 인증 의존성 구현

`api/deps.py`에 관리자 API에서 공통으로 사용할 인증 기능을 추가한다.

```text
current_admin
require_role()
require_reauth()
audit()
```

* 현재 로그인한 관리자 조회
* 역할별 API 접근 제한
* 중요 작업 전 비밀번호 재확인
* 관리자 쓰기 작업의 활동 로그 자동 기록
* 각 Router에서 인증 코드를 반복하지 않도록 공통화

### 5. 활동 로그 연결

* 로그인·로그아웃 결과 기록
* 세션 연장과 재인증 결과 기록
* 관리자 데이터 변경 작업 기록
* 관리자 ID, 작업 종류, 대상, 성공 여부, `request_id` 저장
* 이후 추가되는 모든 관리자 쓰기 API가 활동 로그를 남기도록 공통 구조 적용

### 6. 관리자 화면 연동 검증

* React 관리자 로그인 화면과 인증 API 연결
* 로그인 후 관리자 세션 유지 확인
* 미인증 사용자의 관리자 화면 접근 차단 확인
* 관리자 지식베이스 화면에 실제 DB 데이터 연결
* 관리자 작업 후 활동 로그 저장 여부 확인

검증 흐름:

```text
관리자 로그인
→ httpOnly 쿠키 발급
→ GET /api/admin/session 성공
→ 관리자 화면 진입
→ GET /api/admin/knowledge/pages 조회
→ admin_activity_logs 저장 확인
```
