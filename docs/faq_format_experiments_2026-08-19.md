# FAQ 패러프레이즈 과잉 거절 — 변형 실험 전체 기록 (2026-08-19)

브랜치 `exp/faq-chunk-format-ab`. 도구: `experiments/eval_faq_chunk_format.py`(생성축),
`experiments/eval_summary_prefix.py`(검색축). 표적 문항 3개(추천 칩 2 + 테스트셋 패러프레이즈 1),
지표는 greedy(최빈 응답) 거절 여부 + temp 0.2 샘플링 거절률 + 정답 포함 + 원문 유출.

## 문제 정의

FAQ 청크가 "질문 N. {원문 질문} / 열기 / 답변 / {답}" 구조로 원문 질문을 품고 있고,
사용자 질문이 그 문구와 다르면(패러프레이즈) HCX-DASH-002 가 정답이 근거 top-1 에
있어도 거절한다. 같은 근거에서 질문 문구만 원문으로 바꾸면 100% 정답(문구 대조 실험).
이 거절은 2026-08-10 부터 기록된 원래 상태다(rag_runs: 08-10 성공 0/6) — 회귀가 아니라 발굴.

- 원인: 경쟁 페이지(faq_top10 등)도 같은 어휘의 요약을 받아 **상대 순위 제로섬** + 문장 단위

## 부속 발견

1. **Q2 는 검색 문제**: 청크 단위 top5 가 FAQ 두 페이지 문답으로 도배되고 본편
   (kmrs_aply_trgt 17위·sender_qlfc_check 자가진단 18위)이 프롬프트에 못 들어감.
   페이지 단위로는 3~6위 — 근거 조립의 페이지 다양성 문제(cap 미실험).
2. **프리픽스 무죄**: 프리픽스 도입 전에도 FAQ 검색은 R@5 1.0(A/B 기록) — "프리픽스가
   FAQ 청크를 새로 끌어올려 문제가 생겼다"는 가설은 오류로 철회.
3. 페이지 간 지원 한도 표기 불일치(mtrs_gvbk_proc "5천만원 이하" vs 타 페이지 "1억원
   이하") — 원문 콘텐츠 정합성 이슈, 별도 확인 필요.

## 결론

- 데이터·프롬프트 축은 소진: E(B+C)가 종착점 — 가까운 패러프레이즈 구제 + 유출 제거.
- 먼 패러프레이즈(칩 문항)는 **HCX-DASH-002 의 의미 연결 한계** — 질문을 없애도(F),
  답을 평서문으로 줘도(H) 못 잇는다. 남은 카드:
  1. 칩 문구 검증 교체(원문 '그대로'가 아니라 '가깝게' — Q3 실측이 근거. 후보 문구별
     하네스 사전 검증 후 채택)
  2. 재생성 강화 1→2회(구제율 25%→이론 ~44%)
  3. **생성 모델 업그레이드 실측(HCX-007 A/B)** — 근본 후보, 미측정
  4. (보류) G1 질문 정렬 — 효과 실측된 유일 카드, 가드 설계와 함께 재논의 가치
