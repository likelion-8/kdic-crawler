### 2. 질문 유형별 Corpus 관계 PCA 분석

* 질문과 Corpus 임베딩을 동일한 PCA 축에 2차원으로 투영해 유형별 분포와 오답 연결을 분석함
* PCA 그래프는 실제 검색에 사용되는 1024차원 코사인 유사도가 아니라 질문과 문서의 전체적인 분포를 확인하는 보조 분석으로 사용함

| 질문 유형           | 문항 수 |  Hit@1 |  Hit@5 | 분석 결과                      |
| --------------- | ---: | -----: | -----: | -------------------------- |
| `fact`          |  358 |  58.1% |  89.4% | 정답 후보는 확보하지만 Top-1 정렬이 약함  |
| `table_lookup`  |   80 |  81.3% |  93.8% | 표·수치 질문이 비교적 안정적으로 검색됨     |
| `faq`           |   64 |  81.3% |  96.9% | Top-5 후보 확보가 매우 안정적임       |
| `link_guide`    |   37 |  40.5% |  78.4% | 후보 확보와 Top-1 정렬 모두 가장 취약함  |
| `file_download` |   17 | 100.0% | 100.0% | 현재 평가 문항에서는 모두 Top-1 검색 성공 |

* 그래프에 포함된 556개 문항 기준 전체 성능을 계산함

  * 전체 Hit@1: 약 `64.2%`
  * 전체 Hit@5: 약 `90.5%`
* `fact` 유형은 Hit@1과 Hit@5의 차이가 `31.3%p`로, 검색 실패보다 유사 문서 간 순위 정렬 문제가 큰 것으로 분석함
* `link_guide` 유형은 Hit@1과 Hit@5의 차이가 `37.9%p`로 가장 크게 나타남
* `file_download`는 현재 결과가 좋지만 문항 수가 17개로 적어 추가 질문 확장이 필요함
* 전체적으로 정답 후보를 Top-5 안에 확보하는 능력은 높은 편이지만, 유사 문서 중 정답 문서를 1위로 정렬하는 문제가 주요 병목임을 확인함
* 중복 문서 정답 라벨 수정 후 동일한 조건으로 재평가할 필요가 있음을 정리함

### 3. 복합 질문 하위 답변의 출처 소실 버그 수정

* 복합 질문을 여러 하위 질문으로 분리해 답변할 때 일부 정상 답변의 출처와 URL이 사라지는 문제를 확인함
* 하위 답변 사이에서 공유하던 `seen_pages`, `seen_urls` 누적 집합이 직접적인 원인임을 확인함
* 실제로 출처를 인용했는지가 아니라 검색 결과에 포함됐다는 이유만으로 이미 사용한 출처로 처리되고 있었음
* 앞선 하위 질문이 `[NO_SOURCE]`로 처리돼 출처를 표시하지 않았더라도 검색된 페이지가 누적 집합에 추가되는 문제를 확인함
* 뒤의 정상 하위 질문이 같은 페이지를 근거로 사용하면 출처가 중복으로 판단돼 제거되는 구조였음
* 멀티쿼리 분해기와 Intent 분류기는 직접적인 원인이 아님을 확인함

#### 수정 내용

* 하위 답변 사이의 누적 중복 제거 기능을 삭제함
* `_answer_one()`의 `seen_pages`, `seen_urls` 파라미터를 제거함
* 하위 답변 간 출처 및 URL 필터링 코드를 제거함
* 누적 집합을 생성하고 전달하는 코드를 제거함
* 검색된 페이지를 누적 집합에 추가하는 코드를 제거함
* 각 하위 답변이 자신의 검색 결과를 기준으로 출처를 독립적으로 표시하도록 수정함
* 한 하위 답변 안에서 같은 페이지의 여러 청크를 하나의 출처로 합치는 기존 중복 제거 기능은 유지함

#### 검증 결과

| 검증 시나리오                                | 결과             |
| -------------------------------------- | -------------- |
| `[NO_SOURCE]` 질문 이후 같은 페이지를 사용하는 정상 질문 | 정상 답변에 출처 표시   |
| 단일 질문                                  | 기존과 동일하게 출처 표시 |
| 동일 문서를 여러 하위 답변에서 사용                   | 각 하위 답변에 출처 표시 |

* 단일 질문과 LLM 답변 본문에는 변화가 없음을 확인함
* 복합 질문에서 질문 순서에 따라 출처가 사라지는 문제를 해결함
