- 관리자 작업의 성공·실패 결과 저장

### 3. 관리자 인증 API 구현

관리자 로그인부터 세션 유지까지 필요한 핵심 API를 구현한다.

필수 구현:

```text
POST /api/admin/login
POST /api/admin/logout
GET  /api/admin/session
POST /api/admin/session/extend
POST /api/admin/reauth
```

구현 내용:

- 이메일·비밀번호 검증
- 비밀번호 해시 비교
- 로그인 실패 횟수 증가
- 일정 횟수 초과 시 계정 잠금
- 로그인 성공 시 실패 기록 초기화
- 안전한 세션 ID 생성
- HttpOnly 세션 쿠키 발급
- 절대 만료와 유휴 만료 검사
- 로그아웃 시 세션 폐기
- 세션 연장 시 만료 시간 갱신
- 중요 작업 전 비밀번호 재확인
- 현재 관리자 역할과 권한 반환

시간 여유 시 구현:

```text
GET /api/admin/roles
GET /api/admin/me/permissions
```

### 4. 공통 인증 의존성 구현

`api/deps.py`에 관리자 API에서 재사용할 공통 인증 기능을 추가한다.

```text
current_admin
require_role()
require_reauth()
audit()
```

#### `current_admin`

- 쿠키에서 관리자 세션 ID 조회
- 세션 유효성 및 만료 여부 확인
- 관리자 계정 활성 상태 확인
- 최근 활동 시간 갱신
- 현재 관리자 정보 반환

#### `require_role()`

- API별 최소 관리자 역할 검사
- 권한이 부족하면 `403` 반환
- Router마다 역할 검사를 반복하지 않도록 공통화

#### `require_reauth()`

- 마지막 재인증 시간 확인
- 위험 작업 전 재인증 여부 검사
- 재인증이 만료됐으면 전용 오류 반환

#### `audit()`

- 관리자 작업의 성공·실패 결과 기록
- 관리자 ID, 작업 종류, 대상 ID, `request_id` 저장
- 중요 변경 전후 값을 기록할 수 있도록 공통 구조 구성

### 5. 관리자 활동 로그 연결

다음 인증 관련 작업부터 활동 로그를 연결한다.

```text
LOGIN_SUCCESS
LOGIN_FAILURE
LOGOUT
SESSION_EXTEND
REAUTH_SUCCESS
REAUTH_FAILURE
KNOWLEDGE_LIST_VIEW
```

저장 항목:

- 관리자 ID
- 작업 종류
- 작업 대상
- 성공 여부
- 실패 사유
- IP 또는 요청 정보
- `request_id`
- 발생 시간
- 추가 상세 데이터

민감한 정보인 비밀번호, 세션 ID 전체, 비밀번호 초기화 토큰은 로그에 저장하지 않는다.

### 6. 관리자 지식베이스 조회 API 구현

전체 관리자 기능을 한꺼번에 구현하지 않고, 인증 구조를 검증할 수 있는 읽기 전용 화면 하나를 먼저 연결한다.

대상 API:

```text
GET /api/admin/knowledge/pages
```

구현 범위:

- 인증된 관리자만 접근 가능
- Supabase PostgreSQL에 SQLAlchemy로 직접 연결
- 기존 `documents` 테이블에서 활성 문서 목록 조회
- 페이지네이션 적용
- 제목·URL·업무 분류 기준 검색 및 필터
- 역할별 접근 권한 검사
- 목록 조회 활동 로그 저장
- 프론트 계약에 맞는 응답 형태 반환

응답 예시:

```json
{
  "items": [],
  "total": 0,
  "page": 1,
  "size": 20
}
```

문서 상세, 청크 조회, 신규 URL 등록, 크롤링 미리보기, 승인·반려 기능은 다음 단계로 분리한다.

### 7. Supabase 접근 권한 정리

관리자 인증 구현과 별개로 현재 확인된 보안 문제를 정리한다.

- `anon` 역할의 불필요한 `INSERT`, `UPDATE`, `DELETE`, `TRUNCATE` 권한 회수
- 사용하지 않는 Supabase Data REST API 노출 범위 확인
- Publishable Key가 프론트 환경변수에 포함되지 않았는지 확인
- DB 접속 정보가 백엔드 환경변수에만 존재하는지 확인
- 기존 채팅·피드백·추천 질문 API가 권한 변경 후에도 정상 동작하는지 확인

### 8. 관리자 화면 연동 및 종단 테스트

React 관리자 로그인 화면과 지식베이스 목록 화면 하나를 실제 API에 연결한다.

검증 흐름:

```text
관리자 로그인
→ HttpOnly 쿠키 발급
→ GET /api/admin/session 성공
→ 관리자 화면 진입
→ GET /api/admin/knowledge/pages 성공
→ 제목·업무 분류 검색 및 필터 확인
→ admin_activity_logs 저장 확인
→ 로그아웃
→ 관리자 API 재접근 시 차단 확인
```

추가 오류 상황:

- 잘못된 비밀번호
- 세션 쿠키 없음
- 만료된 세션
- 잠긴 관리자 계정
- 권한이 부족한 관리자
- 재인증이 필요한 작업
