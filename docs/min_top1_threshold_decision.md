# MIN_TOP1_SCORE = 0.35 — 재측정 및 유지 결정 (2026-08-25)

검색 관련성 게이트(`candidate_ranking.gate_low_relevance`)의 임계값을 현재 색인 기준으로
다시 측정하고 **0.35 유지**로 확정한 기록. 2026-08-10 최초 결정의 근거는 아래 2절 사유로
무효가 되어 폐기하고, 이 문서가 대체한다.

## 1. 이 값이 정하는 것

**질문을 차단하는 값이 아니다.** top-1 검색 점수가 임계값 미만이면 **근거를 통째로 비운다.**

```
top = top_k_cut(route_search_chunks(q, k=20), k=5)
if top[0][1] < MIN_TOP1_SCORE:   top = []      # 근거 제거(질문은 계속 진행)
```

빈 근거를 받은 프롬프트는 `prompt_builder.NO_EVIDENCE_NOTICE`로 인사 응대·범위외 거절로
유도된다. 그래서 실험이 답해야 할 질문은 "무관 질문을 얼마나 막나"가 아니라 다음 하나였다.

> 이 임계값에서 인스코프 질문의 근거가 사라지지 않으면서, 무관 질문에는 근거가 안 붙는가?

**점수의 정체**: dense 코사인 유사도 **원값**이다. `PgVectorDenseRetriever`가
`1 - cosine_distance`를 돌려주고, 임베딩이 `normalize_embeddings=True`로 L2 정규화돼 있어
그대로 코사인이 된다(dragonkue/BGE-m3-ko). BM25는 섞이지 않고(`USE_TYPE_ROUTING=False`),
재정규화도 확률화도 없다. **절대 스케일이라 모델·색인이 바뀌면 값 자체가 이동한다.**

## 2. 기존 근거를 왜 폐기했나

2026-08-10 결정의 근거는 "인스코프 137건 top-1 최소 0.378 / 잡담 5건 최대 0.362 → 갭 중간
0.35"였다. 두 전제가 모두 깨졌다.

| 무효 사유 | 내용 |
|---|---|
| **점수 분포 이동** | 2026-08-18 프리픽스 색인 채택(`[제목 · 업무] ` 접두). DB 활성 청크 503/503 적용 확인. 실측상 분포가 통째로 +0.09가량 올라갔다 |
| **잡담이 도달하지 않음** | 2026-08-19 Gate 1(룰)·Gate 2(임베딩)가 검색 **앞**에 생겼다. 당시 근거로 쓴 잡담 5건은 이제 이 게이트까지 오지 않으므로, 잡담으로 임계값을 정하면 Gate 2가 한 일을 중복 계상하게 된다 |

### 4-2. 전 풀 기준으로는 분리 불가 (갭 −0.111)

정답 라벨이 있는 풀만 보면 최솟값이 0.473이라 갭 +0.030으로 "분리 가능"이 나온다. **그건
꼬리가 분모에서 빠진 결과다** — 경계 인스코프 38건은 정답 라벨이 없어 strict 지표에 안
잡힌다. 전 풀 기준 최솟값은 **0.332**이고, 무관 최댓값 0.443보다 아래라 구간이 겹친다.

```
0.332  [인스코프] 자릿수 하나 더 눌러서 딴사람한테 다 가버렸어요 큰일났어요  ← 착오송금
0.334  [잡담]     전주 여행 코스 좀 짜줘
0.335  [범위밖]   예보 직원 월급이 얼마인가요?
0.347  [잡담]     자바스크립트로 배열 정렬하는 법 알려줘
0.443  [개인정보] 친구 계좌 잔액 좀 대신 조회해줄 수 있어?
```

즉 **인스코프 근거를 하나도 잃지 않으면서 무관을 전부 비우는 임계값은 존재하지 않는다.**
어떤 값을 골라도 거래(trade-off)이며, 이 문서는 그 거래를 명시한다.

### 4-4. "손실"이 진짜 손실인지 확인

경계 인스코프가 근거를 잃어도, 애초에 검색이 실패했다면 근거를 비우는 게 **정상 동작**이다.

**검색 실패 차단기**이기도 하다.

### 4-5. 실트래픽 검증

`rag_runs`에서 검색·생성을 실제로 탄 259건 중 게이트가 근거를 비운 건은 **28건(10.8%)**.
내역은 다음과 같다.

> 씨발련아(2) · 씨발 · 아이언맨(3) · 스파이더맨 · asdf · 넌 누구니(2) · 이모지 날려봐 ·
> 멀티턴 · 너무 엄격한거 아니니 · 장정훈이 밥먹으러 안가는데… **+ 착오송금 1건**

**27건은 정당한 차단, 오차단은 1건.** 실측 오차단률 259건 중 1건(0.4%)으로, **0.35는
과차단하고 있지 않다.**

⚠️ 단서: 이 트래픽은 거의 전부 팀 내부 테스트다(욕설·마블 캐릭터 다수). 실사용자 분포가
아니므로 "오차단 0.4%"를 서비스 지표로 그대로 쓰면 안 된다.

## 5. 왜 0.35인가

| 후보 | 판정 | 사유 |
|---|---|---|
| **0.45 이상** | ❌ | 검색이 정확히 맞은 인스코프 2건(0.405 · 0.422)을 잃는다 |
| **0.40** | △ 가능하나 미채택 | 추가로 얻는 것은 `asdf1234` 1건뿐. 진짜 첫 손실 0.405와의 마진이 **0.005**로, 안전 여유가 아니라 우연에 가깝다. 재색인 한 번이면 뒤집힌다 |
| **0.35 (채택)** | ✅ | 무관 제거 84.6%를 확보하면서 실트래픽 오차단 0.4%. 관리자 격자(0.05) 위에서 방어 가능한 값 |
| **0.30~0.33** | ❌ | 무관 제거가 84.6% → 61.5%로 떨어진다. 되찾는 1건은 top-1이 이미 엉뚱한 주제라 근거를 살려도 좋은 답이 안 나온다 |

`0.36~0.39`가 무관 12/13으로 미세하게 낫지만, 얻는 것이 `asdf1234` 하나뿐이라 코드 변경·
재검증 비용을 정당화하지 못한다. 무엇보다 **성공 대상 표본이 13건이라 이 범위의 미세조정은
통계적 의미가 없다.**

관리자 슬라이더 격자가 0.05 단위이므로(`api/routers/admin_rag_params.py`) 최종값은 그 격자
위에 둔다 — 운영 중 조정 가능성을 유지하기 위한 것이다.

## 6. 이 게이트가 하지 못하는 일 (경계)

**인접도메인은 점수로 안 갈린다.** Gate 1·2 생존 무관 48건 중 **35건(73%)이 인접도메인**인데
0.35에서 2.9%(1/35)만 걸린다. 실례로 "국세청 민원은 어디로 접수해?"는 top-1 **0.449**라
이 게이트를 통과한다(실제로는 그 앞의 Gate 2가 `s_ood=0.929`로 잡았다). 이 몫은 Gate 2와
생성 후 `source_check`가 맡는다 — 이 게이트를 올려서 해결하려 하지 말 것.

**검색이 실패한 인스코프는 임계값으로 못 살린다.** 근거를 살려도 엉뚱한 주제가 붙는다.

## 7. 알려진 미해결 건 (1건)

**착오송금 구어체 질문** — "자릿수 하나 더 눌러서 딴사람한테 다 가버렸어요 큰일났어요"

```
Gate 1 CONTINUE · Gate 2 CONTINUE      ← 도메인 내로 올바르게 판정
intent: civil_petition                 ← 민원으로 정확히 분류
검색 top-1 = 0.332  <  0.35
  → gate_low_relevance 가 근거를 비움   ← rag_runs.observation 의 "top": []
  → 빈 근거로 LLM 호출 → source_check: kind=ungrounded_claims
  → 본문을 OUT_OF_SCOPE_MESSAGE 로 교체
32.8초 소비 후 "범위 밖" 응답 (2026-08-25 05:42 실측)
```

**임계값으로 해결되지 않는다.** top-1이 예금자보호제도(미수령금 FAQ)라 근거를 살려도 주제가
어긋난다. 구어체·서사형 질문이 착오송금 페이지를 못 물어오는 **검색/재작성 쪽 과제**로
분리해 다룬다.

## 8. 이 값이 무효가 되는 조건

| 조건 | 영향 |
|---|---|
| **리랭커 ON** (`USE_RERANKER=True`) | 게이트가 보는 점수가 코사인이 아니라 cross-encoder 로짓이 된다. 스케일이 달라 임계값이 통째로 무의미해진다. 도입 시 **게이트를 리랭크 앞의 dense 점수에 걸도록 위치를 고정**하면 이 결과가 그대로 살아남는다 |
| **유형 라우팅 ON** (`USE_TYPE_ROUTING=True`) | link_guide 질문이 `linear_fuse`를 타는데 이건 **질의마다 min-max 정규화**를 한다. 정규화 후 top-1은 구조상 항상 0.6~1.0이라 **게이트가 절대 발동하지 않는다** |
| **임베딩 모델 교체 / 재색인** | 절대 코사인이라 값이 통째로 이동한다. 프리픽스 색인 하나로 +0.09 움직인 것이 그 증거다 |
