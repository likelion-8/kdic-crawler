## 왜 이 창·이 필터인가 (제외 건수)

- **웹 경로 토큰·비용 관측은 08-26부터만 있다.** 그 전 web_chat 트레이스는 관측 1개·비용 0·지연 0.001s (계측 미배포). → 08-14~25 는 **확인 불가**.
- 08-26~28 웹 질문 398 중: 트레이스 미매칭 79 · 트레이스는 있으나 관측 0인 '완료' 69(확인 불가로 제외) · **HCX-007 호출 포함 112 제외**(08-28 14시대 87회·93세션 — 일괄 테스트로 추정) → 138.
- Langfuse `environment` 는 전부 `default`, 팀 테스트를 가르는 필드(user_id·tags·IP) 없음 → **prod/dev·팀 테스트 분리 불가**. 이 138건도 대부분 팀 테스트다.
- `rag_runs.llm_model` 은 전부 NULL — 모델은 Langfuse `model` 로만 구분된다.
- SDK `observations.get_many()` 는 usage/cost 를 비워서 돌려준다 → REST 직접 호출.

## 검토 항목 — 여기에 답해 달라

1. **HCX-007 제외가 맞나.** 08-28 14시대 007 호출 87회가 누가 뭘 돌린 건지 아는 사람? 실사용이었으면 제외하면 안 된다.
2. **"관측 0인 완료 69건"** — 계측 누락인지, tracing 꺼진 다른 서버 프로세스에서 나온 건지. 0원으로 분모에 넣으면 A 가 2.24 → 1.5원대로 내려간다. 어느 처리가 맞나.
3. **A 의 분모** — Gate1(LLM 0)은 넣고 확인 불가는 뺐다. "질문당 평균"으로 합당한가.
4. **재생성 식별** — 웹 트레이스 안의 `call_hyperclova` 를 전부 재생성으로 봤다. 웹 경로에서 그 이름으로 도는 다른 호출이 있나 (query_decomposer 는 use_query_planner=False 일 때만이라 없다고 봤다).
5. **캐시 적중 = Triage 1회** — sse.py 순서상 Triage(0-2) 뒤에 캐시 조회(0-3). 맞나.
6. **OUT_OF_SCOPE 정의** — 발표에 "범위 밖 N건" 표현이 있으면 이 정의로는 틀리다. 고쳐야 하나.
7. **Langfuse vs 단가 1.1% 차이** — Langfuse 에 등록된 DASH-002 단가(USD)를 UI 에서 확인해 달라. API 로는 못 봤다.
8. **08-29 이후 창** — 정당한 거절 재생성 제거(PR #209) 뒤 B 가 얼마나 내려가는지, `--from 2026-08-28T15:00Z` 로 하루치라도 돌려 봐 달라 (extract 도 `--to` 를 늦춰서).

발표 문안 후보: **"조기 종료 포함 2.2원 / 생성까지 간 질문 4.2원 / 재생성 없는 단일 질문 3원"** — 이 세 개를 같이 말하는 게 로그로 방어되는지 의견도.
