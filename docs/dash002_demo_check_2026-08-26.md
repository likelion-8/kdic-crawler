## 3. 대본에서 고칠 것 (모델 무관)

"신청 절차는 어떻게 되나요?" 하위질문은 근거 페이지가 절차 안내라 첨부에 **신청 링크만** 붙는다. 서류 첨부는
서류를 묻는 질문에 붙는다 — "착오송금 반환지원을 신청하려면 어떤 서류가 필요한가요?" 실행 시 첨부 2개
(서류) + 답변에 신분증·신청서·위임장 등 열거. 선택지:
- 복합 질문을 **"대상 금액은 얼마까지이고, 신청하려면 어떤 서류가 필요한가요?"** 로 바꾸면 대본 문장
  ("필요한 서류와 공식 신청 페이지") 그대로 보여줄 수 있다 — 단 서류 질문은 절차 질문보다 첨부 확인 후 재확인해 볼 것
- 또는 대본 문장을 "공식 신청 페이지 링크까지 함께 제공"으로 줄인다

## 4. 같이 발견한 것

- `rag_runs.llm_model` 이 None 으로 남는다(`question_type`·`retrieval_route` 도). 관리자 로그에서 "이 답변이 어느
  모델로 생성됐나"를 못 본다 — 모델 전환 전후를 로그로 보여주려면 채워야 한다(sse 경로 `log_run` 호출부).
- 429 재시도: `llm_client.MAX_RETRIES=5`(openai SDK 백오프)를 이 브랜치에서 넣었다. 89문항 A/B 에서 두 모델
  모두 SDK 기본 2회를 넘겨 실패한 건이 있었다.
- 캐시 스냅샷에 `model` 이 들어 있어(`answer._cache_versions`) DASH 로 실행하면 같은 질문의 007 캐시 행이
  버전 불일치로 **지워지고 DASH 답변으로 교체**된다. 리허설을 007로 먼저 하고 DASH 로 바꾸면(또는 반대)
  캐시 장면은 다시 한 번 적재부터 해야 한다.
